# Sample 5-Part Task Packet

```markdown
## Goal
Implement a custom sorting algorithm `custom_sort(arr)` that places even numbers before odd numbers, both sorted in ascending order.

## Files/Ownership
- `src/utils/sorter.py`
- `tests/test_sorter.py`

## Interfaces
- `def custom_sort(arr: list[int]) -> list[int]`

## Constraints
- Must handle negative integers and empty arrays cleanly.
- Must execute in $O(N \log N)$ time complexity.

## Verification
- `pytest tests/test_sorter.py`
```
